# Community special agents

The community special agents look after the places people talk about
ForkMesh outside the product: Hearth hosts the Discord server and the Reddit
scout finds threads where ForkMesh can honestly help. Each page is that
agent's charter, read before every run. Marketing owns the channel plan
([marketing charter](../marketing/README.md)). Back to
[the documentation home](../README.md).

| Page | Covers |
| --- | --- |
| [hearth.md](hearth.md) | Hearth, the Discord host: `tools/discord_community.py`, voice and rules, rhythm, health measures, security |
| [reddit.md](reddit.md) | The Reddit scout: why it never posts, `tools/reddit_scout.py`, the watchlist, how it decides, the Reddit desk, the u/forkmesh profile |

Both agents are checked in paused, treat every message they read as
untrusted content, and never present a bot as a person. Claims they make
trace to the docs, starting with the core pages:
[architecture](../architecture.md), [encryption](../encryption.md),
[mirroring](../mirroring.md), [self-hosting](../self-hosting.md),
[censorship resilience](../censorship-resilience.md) and the
[threat model](../protocol/threat-model.md).
