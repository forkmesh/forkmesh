# Operator files

Part of [Operations](README.md).

Where the fleet's code lives in this repository and where the operator box
keeps the fleet's secrets, keys, state and logs. No secret is in the
repository: `deploy/fleet.toml` names every secret by credential name only.
How the stack fits together: [served stack](served-stack.md); what to run:
[runbook](runbook.md).

## Code

The stack's code is part of this repository: `app/host/`, `deploy/`,
`tools/next_*.py` and `tools/cutover_*.py`. It was built in its own
repository and is now production. `tools/next_import.py` can replay the old
separate repository's history onto a branch here; it is deterministic,
refuses to rewind a diverged branch without `--force`, and is tested by
`deploy/tests/test_next_import.py`.

## Folders

Operator state lives under the never-erase project folders (`AGENTS.md`).
The real folders are `~/projects/forkmesh/data/core/{config,ssh,logs}/fleet`
and `data/core/fleet`; the `~/projects/forkmesh/<root>` links below reach
them ([projects layout](../tools/projects-layout.md)):

| Folder | Holds |
|---|---|
| `~/projects/forkmesh/config/fleet/` | the files in the next table, `ids-operator.key`, `known_hosts`, deploy and autodeploy locks and manifests, `add-core/` and `remove-core/` run state |
| `~/projects/forkmesh/ssh/fleet/` | the fleet SSH key and its `known_hosts` |
| `~/projects/forkmesh/data/fleet/` | `backups/`, `dist/` (release tarballs and the mirror-node binary), `dl/` (the pinned rqlite and Caddy tarballs; sha256 in `deploy/fleet.toml`, checked on both ends), `bin/` (rqlite and Caddy for tests) |
| `~/projects/forkmesh/logs/fleet/` | tool and run logs |

`config/fleet/` is mode 0700 and its files 0600. There is no object storage:
backups are pulled to the operator box and certificates are shared over
WireGuard.

## Files in `config/fleet/`

| File | Contents |
|---|---|
| `vultr.env` | `VULTR_API_KEY`. Tools touch only instances labelled `fmnext-*` and tagged `forkmesh-next`. Prefer a sub-user limited to instances. |
| `aws.env` | optional AWS credentials for an IAM user with only the fleet policy ([fleet tooling](fleet-tooling.md#iam-policy)) |
| `cloudflare-dns.env` | `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ZONE_ID`: the DNS token file `next_dns.py` reads; scope it to DNS edit on the zone |
| `cloudflare.env` | account token for the `forkmesh-www` Worker deploy and the cutover tools |
| `secrets.env` | `DATA_KEY`, `ADMIN_PASS`, router seed and public key, `FORKMESH_MESH_SECRET`, `FORKMESH_CERTSYNC_SECRET`, `WWW_EDGE_SECRET`, `RQLITE_PASSWORD`, integration values. Generated by `next_fleet.py init-secrets`. |
| `DATA_KEY` (0400) | the vault key alone; keep an offline copy |
| `fleet-instances.json` | label → instance id, plan, region, IPv4, IPv6: the only place node addresses are kept ([node addresses](fleet-tooling.md#node-addresses)) |
| `fleet-state.json` | WireGuard and IDS public keys |
| `dns-health.json` | per-node health counters, `in_dns`, `held` |

## Paths in the tools

`tools/forkmesh_paths.py` is the one source for these paths; `next_common`
derives `config_dir()`, `ssh_key_path()`, `data_dir()` and `logs_dir()` from it.
The overrides `FMNEXT_CONFIG_DIR`, `FMNEXT_SSH_KEY`,
`FMNEXT_DATA_DIR`, `FMNEXT_LOGS_DIR`, `FMNEXT_BACKUPS_DIR` and
`FMNEXT_DIST_DIR` let an operator point the tools elsewhere without moving
anything.

## Rules

- Copy, never move, operator state. Delete a copy only by explicit file name.
- The hourly minimal backup must not archive `config/fleet` or `ssh/fleet` in
  plaintext; those folders are backed up encrypted.
- The private backup decryption key belongs offline, not next to the backups.
- The operator units (`fmnext-backup`, `fmnext-unseal`, `fmnext-dns-health`)
  run the repository venv from `~/projects/forkmesh/src`; that venv needs
  `cryptography`.
- `~/projects/forkmesh-backup` is the retired folder of the old repository,
  kept as a backup. Never erase it.
- Remote node paths (`/etc/forkmesh-next`, `/opt/forkmesh-next`,
  `/var/lib/forkmesh-next`) and the `forkmesh-next` instance tag are identity
  names, not operator paths, and do not change.
