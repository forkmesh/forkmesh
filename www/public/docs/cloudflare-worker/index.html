ForkMesh App & relay

The Python application in app/ serves the Git product UI, REST API, realtime routes, and encrypted repository rooms. The canonical official origin is https://app.forkmesh.com.

Where it runs

Until September 2026 the hosted App ran as a Cloudflare Python Worker. Since 24 September 2026, app.forkmesh.com and world.forkmesh.com run the same Python application on ForkMesh's own servers. The landing pages, docs, and blog at forkmesh.com are a separate static site in www/. This page keeps its old address so existing links still work.

To run your own instance, follow Self-hosting a mainnode in the protocol spec.

Rooms and catalog

Repository rooms connect over a WebSocket at:

/api/repo/{owner}/{repo}/rooms/{room}/ws

The older /api/room/{room}/ws path remains as a temporary compatibility endpoint. The official ForkMesh room is: 

wss://app.forkmesh.com/api/repo/mainnode/forkmesh/rooms/general/ws

Go mirror services publish signed metadata to the repository catalog at /api/repositories, which the product UI reads to render the network repository list. The App stores signed metadata only, not local filesystem paths or Git object data.

Room encryption

Every room frame leaves the client inside an AES-256-GCM outer cipher whose passphrase the server can derive. Public channels intentionally stop at that controller-readable layer so ForkBot, MCP, and webhooks can participate. Private channels and direct messages first encrypt each application frame under a fresh content key and wrap that key to known X25519 device identities, so the controller room key alone cannot read protected content. Device discovery is automatic but not independently authenticated: an active controller can inject a future recipient key. Frames marked persist: true are kept for at most 7 days, with only the newest 500 retained per room; other frames are broadcast without history storage.
