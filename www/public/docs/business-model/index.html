Contract version 1 · published August 20, 2026

Free protocol.
Paid service.

ForkMesh lets developers collaborate on, mirror, and preserve source-code repositories across independent hosts—without relying on any single hosting provider. We charge for operating replaceable services and taking responsibility for them. We do not charge for permission to use, self-host, fork, or participate in the protocol.

The permanent line: protocol rights, MIT-licensed software, independent implementations, self-hosting, anonymous public read and clone, portable Git data, signed collaboration records, and governance do not become paid features. A paid customer receives service—never control over the protocol.

Measured before sale

Observable usage units

Managed proposals use units that correspond to a service-cost source. Unknown cost remains unknown—never zero—and blocks an unlimited or margin claim.

  • Active member-month
  • Indexed project-month
  • Managed replica GiB-month
  • Verified egress GiB
  • Hosted runner minute
  • Priority support hour
  • Edge Worker request
  • Durable Object request
  • Durable Object GB-second

Portability commitment

Leaving is a supported path.

Canonical repositories remain standard Git objects and refs. Canonical collaboration remains signed .forkmesh repository records. Clone and export do not require an upgrade or export fee, including before cancellation. A managed launch must prove export into a clean self-hosted deployment and restore from the same records without changing object ids or signatures.

No data sale: ForkMesh does not sell personal data, repository data, collaboration data, telemetry, or derived profiles, and does not use them to sell advertising. Optional coarse analytics remains disabled by default.

Support boundary

Responsibility is the product.

Community support includes public docs and reproducible issue reports, with no response-time or uptime promise. A future paid order must name supported platforms, contact hours, response target, exclusions, escalation, data-access boundary, and included human time. ForkMesh does not promise an SLO for self-hosted systems it does not operate.

Current evidence

Managed pricing is not validated yet.

The current register contains zero qualifying buyer interviews. Buyer, budget, and paid-job ordering remain hypotheses, so managed checkout is disabled. Real, consented decision-maker interviews—not comments, analytics, internal opinions, or synthetic notes—must cause documented revisions before a price launches.
