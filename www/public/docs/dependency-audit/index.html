Headline findings

  1. No open advisory matches any pinned version in any ecosystem; OSV was queried per package and exact version.
  2. The Go toolchain is the mirror node's main dependency. The mirror node uses only the Go standard library, so it is kept current by rebuilding with new Go toolchain releases; no code change is needed.
  3. Stale but low risk. The oldest pinned npm version is fsevents 2.3.2 (Feb 2021), an optional macOS-only Playwright dependency. @types/node and undici-types in the VS Code extension are over a hundred releases behind because they follow the extension's VS Code ≥ 1.75 floor; they are typings, not runtime code.
  4. Highest-value upgrades: @types/node 18 → 26 in the VS Code extension, Kotlin 2.4.0 → 2.4.20, Android Gradle Plugin 9.1.0 → 9.4.0, Playwright 1.61 → 1.63.
