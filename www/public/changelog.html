Changelog

Every release, in plain English

How ForkMesh grew — from a single mirror on one laptop to an agent-powered, community-run developer mesh. The ForkMesh apps show these same notes under What's new.

October 24, 2026

Market

  • The Tour plugin lets you choose Essentials, Advanced or The whole shebang, and on iPhone each stop is a live copy of the screen it describes that you can try before opening the real one.

Calls

  • Direct calls can use your avatar as your face, and group calls now apply your chosen face and voice on every connection.

Projects

  • Mirrored issues link back to the original on GitHub or Gitea, show the imported avatars, and can list threads newest first with their last commenters (the Forum-style issue lists plugin).
  • Long issue threads open faster: the page arrives with the whole thread, sent in parts, and the dashboard takes it over in place.
  • Instances can turn on Atom feeds of a repository's issues, a lite view of every thread that works without JavaScript, and a forum-style home page (the Feeds and lite view plugin); white label is an install setting.
  • Repositories can set a goal for independent mirrors, see how healthy each listed mirror is, and ask readers to run one (the Mirror goal plugin).
  • Images and files in mirrored GitHub threads are copied into the repository, so issue pages show them without loading anything from GitHub (the Mirrored attachments plugin).
  • Posts in other languages get a Translate bar that translates on your device or shows the instance's own English translation, and members can add their own translations (the Translations plugins).
  • Issue pages load faster on mirrored forums: imported avatars are cached, names are checked in one request per page, and Translate bars appear without slowing the thread.
  • Merging a pull request or updating its branch from the web shows each step live, from handing it to a mirror to publishing the result.

Chat

  • Links to a channel or direct message open it even on a freshly loaded chat page.

World

  • World retries with its lighter renderer when a computer's graphics cannot start the full 3D view, instead of going straight to the "could not start the 3D renderer" page.
  • Talk in the World with your microphone and camera: join the whole World, a World channel, a voice room you start, or a privacy bubble with the people next to you, while your camera moves your avatar's face, head and hands, hand gestures send reactions to whoever is speaking, and every speaker wears a live word count.
  • One channel list now holds the World channels, voice rooms, Office rooms, your channels and your direct messages, and opens conversations right in the World.

World

  • A neighbour's hexagon with a bug terrarium now draws in about a third of the steps it used to, so the World runs smoother near it.

Settings

  • Instances can use a GitHub-style theme that follows each visitor's light or dark system setting, and Settings, Appearance has a System choice.

iPhone

  • A new install asks for nothing at launch: a short screen explains which permissions may come up and why, and each one is asked only when you first use the feature that needs it.

Desktop

  • In the desktop's live database Visualizer, clicking a table opens that table in the Database tab.
  • In the new desktop design, Control, Network, Repos, Git, Files, Memory, Tasks, Chat, Settings, Users, Pings, Ledger, Analytics, Market, Stats, Health, Calendar, Specials and Calories are restyled to match, with a board view for tasks, a node detail panel, a places column in Files, repository cards, a Market grid, wallet QR codes in Ledger, a relay switcher in the sidebar and a table in Settings for choosing where each app shows up.
  • The debug bar's Report and Send diagnostic buttons are now one Diagnose button that turns red when it spots a performance, security or UI problem, and one click starts an agent with the model you have selected.
  • Merge all with AI now rebuilds a pull request from a stacked series whose earlier parts were already merged, instead of leaving it out because its code is not on this computer.
  • The install line on the homepage has a small Binary / Source switch, so you can copy the command that compiles ForkMesh from source.
  • Switching theme or interface from the View menu is several times faster and no longer freezes the window for many seconds.
  • The desktop prompt now names the chat channel you are in, with a menu to switch channel that shows each channel's users and chats, its three preview lines show the latest chat messages with channel, name and time, the send-to button reads chat, and the pop-out button is gone: drag the prompt by any part of its body to move it anywhere or out into its own window, and resize it from any edge or corner.
  • The desktop app freezes less while the disk is busy: Action logs and run status, saved-search runs and quick-fix choices are written in the background, and the Genie spider no longer rewrites your settings each time it wanders.
  • Drag a pinned workflow between the top, left, right and bottom strips, and drag a left-rail icon back onto the repository tab bar or Code toolbar.
  • The desktop's View menu can reset the look to the default a fresh install starts with, or match the theme of the instance you are connected to.
  • A spare disk labelled TMP now takes agent scratch folders, build caches and Action sandboxes, is cleaned on every start, can be erased from Settings, and shows in the debug bar alongside a warning when a USB drive is plugged into a slower port than it supports.
  • The Restart button now tells you which changed files it rebuilt, or that nothing changed since the last build.
  • The right-hand rail is now a side rail you fill yourself: drag workflows, special agents, pages and links onto it, open a small browser beside it, and open terminals as tabs in the window from it or the top bar, which Claude Code and your agents can read and type into while you share them.

Server

  • Instances have a privacy mode: nothing about visitors is logged or sent, and the footer says so.
  • The Start your own instance page has a one-line prompt you can paste into Claude Code or another coding agent, which then sets up your instance with you.

v0.7.0 July 2026

The Living Code City

ForkMesh becomes a shared three-dimensional developer world backed by independently operated repository mirrors.

  • Everyone enters the World. Guests and members share the Town Square, see live avatar movement, and can use the embedded public World chat without leaving the scene.
  • Resilient repository routes. Public smart-HTTP traffic is proxied through healthy, signed mirrors with automatic failover and round-robin selection.
  • SSH Git access. Users can register an OpenSSH public key and clone or push through the permission-checked Git gateway; private keys remain on their own device.
  • Non-custodial community rewards. Contributors can fund the transparent public Solana pool directly from a self-custodial wallet. ForkMesh never stores contributor or node-operator private keys.
  • Privacy-safe identity. Clothing badges use optional approximate country, browser, and operating-system symbols without publishing raw IP addresses or precise location.
  • Operational clarity. World notifications, repository integrity proofs, security scan scope, and infrastructure metaphors link back to the technical state they represent.
v0.5.0 June 2026

The Agent Mesh

The release where ForkMesh starts to feel alive. Open an issue, hand it to an AI agent, and watch a real pull request show up — all without leaving the mesh.

  • Built-in coding agents. Assign any issue to Claude Code or Codex from the issue detail or quick-add box. The agent works on your connected fork and opens a pull request when it's done.
  • A real terminal, in the app. A native VT100 terminal renders every agent and workflow run with full color output and emoji.
  • Legacy issue bounties. This release originally added a custodial issue-bounty flow. That flow has since been retired: please do not send funds to historical bounty addresses.
  • VS Code Marketplace plugin. Optionally browse issues and kick off ForkMesh agents from your editor without installing the plugin in the base desktop app.
  • Profile pages. Click any node to see its full public profile — repos, identity, and version.
  • Hardened by default. Tighter signup and relay security, with auto-publish off until you say so.
v0.4.0 June 2026

Autonomous Agents

Collaboration stopped being a one-person job.

  • Parallel agents, no queue. Run multiple agents at once across your issues.
  • Continue the conversation. Pick a session back up where it left off, with auto-PR creation on quick tasks.
  • Live activity indicators. See which agents are working right now.
  • Issues and PRs that talk to each other. Merge a PR and its linked issue closes itself; sync straight to main with one checkbox.
  • One-click delegation. Send any issue to your agent of choice — pre-filled and ready to go.
v0.3.0 June 2026

Identity & Rewards

ForkMesh added optional community-funded incentives for healthy mirror operators.

  • Guest-first access. Visitors enter the world immediately; registered accounts use email, password, and email verification.
  • Solana payouts and contributions. Publish a self-custodial payout address or voluntarily fund the public mainnet-beta community pool with a direct transfer signed in your own wallet. ForkMesh never receives a community member’s wallet key.
  • Rewards for mirroring. Eligible, integrity-verified nodes may be selected for a community incentive; participation, payment, and financial returns are never guaranteed.
  • Network presence, done right. Mirror-sync notices moved into a proper network log, with live connection alerts.
v0.2.0 June 2026

Collaborate Anywhere

The web caught up to the desktop, and ForkMesh went mobile.

  • Pull requests. Signed patch submissions, browsable on the web and mergeable from the client.
  • Actions. Run shell-step workflows on push on your own desktop, with the latest live log one click away.
  • Releases and tags. See your tags, mark the current one, and cut new releases in seconds.
  • Browse before you mirror. Explore files, commits, and rich diffs (images side by side) — no clone required.
  • ForkMesh on your phone. Browse repositories, follow activity, chat, and submit signed collaboration updates. The mobile app is an access client; Git mirroring remains a desktop/headless-node job.
  • Fork with intent. Choose exactly where a fork lands in your working tree.
v0.1.0 June 2026

Genesis

The first commit. A bet that source code shouldn't be locked to a single forge.

  • A distributed mirror network. Local Git mirrors, signed identities, and a Cloudflare relay that coordinates without ever holding your objects.
  • A public catalog. Public repositories and clearly labeled external stubs, with actively mirrored repository bytes streamed over HTTPS from a selected healthy origin.
  • Issues that grow with you. Open/closed states, priorities, custom fields, a Kanban board, and milestones with progress bars.
  • Commit history and diffs, viewable right in the browser.
  • Authenticated shared-key room chat. Genesis shipped client-encrypted transport whose default passphrase the relay could derive. Current public channels intentionally retain that integration-compatible boundary; private channels and direct messages now add automatic device-recipient encryption beyond it. Persisted frames remain limited to 500 per room for 7 days.
  • One-click hand-off to your AI tools, baked in from day one.
