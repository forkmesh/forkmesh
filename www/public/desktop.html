Desktop app

Install ForkMesh Desktop

The desktop client manages local working copies and talks directly to your mirror hosts. A compact Go mirror service, not the GUI, serves clone traffic and publishes repository state.

$ curl -fsSL https://forkmesh.com/install.sh | bash

The command-line installer uses authenticated prebuilt binaries and never compiles as an implicit fallback. If your package is not published, follow the source-build prerequisites instead.

Setup steps

macOS

Use a published DMG when shown above; otherwise this release has no verified native macOS package. The DMG is not notarized yet, so macOS warns the first time you open ForkMesh.

  1. Choose the Apple silicon or Intel DMG in the download card above.
  2. Open the downloaded DMG and drag ForkMesh to Applications.
  3. Open ForkMesh from Applications. If macOS blocks it, open System Settings, choose Privacy & Security, and click Open Anyway.
  4. Sign in and connect a mirror.

Windows

Use the setup executable when shown above; otherwise this release has no verified native Windows package.

  1. Download the Windows setup executable from the card above.
  2. Open it and follow the short per-user installation wizard.
  3. Launch ForkMesh from the Start menu or desktop shortcut.

Linux

The card names the exact published format; package contents and setup differ.

  1. Download the asset matching your CPU from the card above.
  2. For a bare binary, run chmod +x forkmesh-linux-x86_64, then launch it from a terminal.
  3. For an AppImage, mark it executable and run it; an AppDir.tar.gz archive must be unpacked first.
  4. Headless servers: when run as root on a machine with no display, the installer prepares a background mirror service instead of a desktop window, so your repositories stay online when your computer is off. It needs a public hostname before it starts. See the docs for hosting a mirror.

After installing

Sign in, connect a local repository, and it goes live on the network.

  1. Create an account or log in from the app or the website.
  2. Add a local Git repo as a mirror and bring it online.
  3. Read the Quickstart for hosting, tunnels, and issues.
