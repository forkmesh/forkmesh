Product update

What's new: a new look, starter packs and view-once messages

A week of shipping since our last update: ForkMesh has a new logo and a calmer dashboard, new phone projects let you choose how much to start with, direct messages can disappear after one view, and the servers behind forkmesh.com can now change without anyone noticing.

October 14, 2026Product update5 min read

The picture at the top is our new logo: a cube with the mesh on its lid and an F and an M on its sides. The two coloured copies branching off it are what ForkMesh is for: a fork of your project that is just as complete as the original, wherever it lives.

A new look on the web

The dashboard now takes every colour and size from one file, so pages finally agree with each other. Blue marks links, focus, selection and the current tab; green is kept for the one button on a page that creates something new, and for status. Controls are more compact, and headers are plain.

  • Agents is a run list you can scan at a glance, and the agent composer is smaller and quicker to type into.
  • Runners is one flat list.
  • The new repository form and the repository pages were rebuilt.
  • Profile badges are drawn as real medallions.
  • The Apps page has tabs and a plugin list you can search.
  • Emails from ForkMesh use a simpler "Letter" layout, with the link written out and an email-settings link at the bottom.

Start a phone project your way

New projects on iPhone and Android used to open almost empty. Now the first time a new project opens, it asks once how you want to start:

  • Minimal: just your code. No agents, chat or inbox until you add them.
  • Standard (the default): Agents, Chat, Inbox, Code and the tour.
  • Everything: every package the phone has.

You can add or remove anything later from the Market. Projects you already have keep what they had. A phone project also no longer needs an instance: you can create and edit repositories on the device and pick a server later.

Signing in got friendlier too. Login has a Forgot password? link, and on iPhone, sign-up opens in a sheet inside the app and brings you back to the login form when you're done. Accounts are still only created on our secure sign-up page, behind the same browser check as on the web.

Messages that disappear after one view

In direct messages on the web, iPhone and Android, you can record a view-once video or voice message. It plays once and is gone. Until it's opened, you can unsend it, and the read receipt waits until it is opened, expires or is withdrawn. Video messages can use face and background filters, and voice messages a voice changer, so you can hear yourself before you send.

Chat picked up plenty more:

  • #general, #random and #welcome are real channels for everyone, on every client.
  • Links show previews.
  • Messages can be deleted for everyone.
  • DMs show who is typing, and you can block someone.
  • You get an email reminder when a direct message has been waiting for a day.

Calls have a pre-call preview, a choice of backgrounds and a cleaner cut-out around you.

Servers that can change under you

forkmesh.com runs on our own small group of core servers. This week we added a new core and retired an old one. Retiring it stopped pushes for about 45 minutes, because the old core still owned the main repository; that is fixed, and adding or removing a core is now a routine step rather than an event. A new core joins locked down from its first boot, links to its owner on its own and starts serving as soon as its checks pass.

Every change still has to earn its way out. Automatic deploys now run the Go tests and the security test suite and refuse to ship if either fails. CI runs the same checks, along with a scanner that fails the build when code deletes files without the safety guards. Notification emails for a new pull request now arrive once, not twice.

Also new

  • Personal runners work on macOS.
  • The CRM on the web matches the desktop: pipeline tabs, multi-select, sorting, pictures and imports.
  • The People plugin shows members in campfire rings, with Follow and Message on every platform.
  • The docs library ships inside the iPhone and Android apps.
  • Agent controls that can't run on your setup are greyed out and link to what you need.
  • Usage bars show seven-day and five-hour windows, and the phone shows your pace.

Many of this week's changes came from community pull requests. Thank you to everyone who sent one, and especially to Kaif, who opened about thirty this week.

Try it

Open the dashboard to see the new look, or get the phone app from forkmesh.com/mobile and start a new project. If something looks off, open an issue on forkmesh/forkmesh or tell us in the ForkMesh Discord. Thanks for reading.
