Marketplace plugins

VS Code Marketplace plugin

ForkMesh issues in your editor's sidebar, with one-click handoffs to Claude Code or Codex. The plugin is optional and is not installed by the base desktop app.

Feature 70 of 72PluginMarketplace3 min read

Why it matters

The VS Code plugin gives ForkMesh an optional path for issue browsing and agent handoffs inside familiar editors. It lists repository-backed issues and can start Claude Code or Codex with an issue-specific prompt.

Keeping that workflow as a Marketplace plugin lets editor support evolve independently. ForkMesh Desktop does not install or activate it, and the rest of the base system works without it.

How ForkMesh handles it

The complete TypeScript source, permission declarations, preview, and build metadata live in the shared ForkMesh Marketplace package. Its manifest is opt-in, declares only an IDE entry point, and has no desktop entry point.

The desktop Market therefore presents it as catalog content rather than claiming it is running. Until an IDE runtime is added to the Market, developers can build the VSIX from the package source and install it explicitly in VS Code, Cursor, Windsurf, VSCodium, or another compatible editor.

The plugin is available from the Marketplace catalog, but it is not part of a default ForkMesh installation.

Where it fits

Install the plugin when you want repository issues and agent launch commands inside your existing editor. Leave it uninstalled when the desktop, web, mobile, or MCP workflows already cover your needs.

Open the ForkMesh Market to review the plugin's manifest, permissions, source availability, and current runtime status.
