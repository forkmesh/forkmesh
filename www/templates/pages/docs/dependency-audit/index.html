Headline findings

  1. No open advisory matches any pinned version in any ecosystem; OSV was queried per package and exact version. The four advisories that exist in package histories (archive ×2, http, shared_preferences_android) were fixed years before the versions in use.
  2. The Go toolchain is the mirror node's main dependency. The mirror node uses only the Go standard library, so it is kept current by rebuilding with new Go toolchain releases; no code change is needed.
  3. Stale but not abandoned. The oldest pinned versions are js 0.6.7 (Jan 2023), path_provider_linux 2.2.1 (Aug 2023) and flutter_secure_storage_web/windows (May 2024). No package in use has gone more than 20 months without an upstream release; the least active is flutter_secure_storage_macos (Jan 2025).
  4. Highest-value upgrades: flutter_secure_storage 9.2.4 → 11.1.1 (16 releases behind, holds the account keys), file_picker 10.3.10 → 12.3.0, archive 4.2.0 → 4.3.0, @types/node 18 → 26 in the VS Code extension, Flutter 3.47.0 → 3.47.4, Kotlin 2.4.0 → 2.4.20, Android Gradle Plugin 9.1.0 → 9.4.0.
  5. Supply-chain concentration is healthy. 106 of 128 Dart packages come from Google-run publishers; the community publishers are long-standing, verified, and all released within the last five months.
