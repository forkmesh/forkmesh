Boilerplate

Short

ForkMesh lets developers collaborate on, mirror, and preserve source-code repositories across independent hosts—without relying on any single hosting provider.

Medium

ForkMesh is an MIT-licensed code forge built so a repository can outlive any one host. Repositories are copied to independently operated mirror nodes, and an ordinary Git clone of forkmesh.com/owner/repo is routed to a healthy, integrity-checked mirror, even while the source host is offline. Issues, pull requests and reviews are signed with each person's own key, and ForkMesh runs on Linux, macOS, Windows, iPhone, Android and the web.

Long

ForkMesh lets developers collaborate on, mirror, and preserve source-code repositories across independent hosts—without relying on any single hosting provider. Repositories are kept as full Git mirrors on independently operated nodes: desktops, servers and headless Linux machines that anyone can turn into a mirror with one install command. A routing layer stores signed discovery and health metadata, never the repository itself, and sends ordinary Git clone traffic to a fresh mirror whose history matches what the author published.

Around that sits a complete forge: issues and milestones, signed pull requests and reviews, releases, encrypted chat, shell-step CI on your own desktop, a marketplace of signed extensions, agents and themes, and AI agents that can pick up an issue and open a pull request. People and nodes are identified by local Ed25519 keys rather than passwords. ForkMesh ships as desktop apps for Linux, macOS and Windows, an iPhone and iPad app, a signed Android APK and a web dashboard, and forkmesh.com itself is served from three self-hosted core nodes. The source code is published under the MIT License.

The public proof uses ordinary developer actions: collaborate, add a mirror, take the source host offline, and clone again.
