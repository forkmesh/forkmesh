# When ForkMesh fits, and when it does not

This page compares ForkMesh with other ways to host and keep Git repositories,
so you can decide whether it fits before migrating. Evidence ledger:
[`ledger.json`](../../conformance/category-comparisons/v1/ledger.json); check
tool: [`category_comparisons.py`](../../tools/category_comparisons.py).

## How to read the comparison

- *ForkMesh protocol and self-hosted software* is what anyone can run from this
  repository; *ForkMesh hosted service* is what forkmesh.com operates. A
  capability in one column does not imply the other.
- Other columns describe a category of tool. A cell that names a product quotes
  that product's documentation, listed under *Primary sources* with its check date.
- **By definition** marks a statement that follows from what the category is.
  **No claim made** means no primary source supports a category-wide statement.

## Known limitations

- HTTPS and mirror-failover Git paths are read-only; publish branches with the SSH URL. Evidence: [`git-compatibility.md` §https-and-failover-paths-are-read-only](git-compatibility.md#https-and-failover-paths-are-read-only). Verified 2026-09-14.
- Hooks pushed with a repository never run on a mirror; shared checks belong in ForkMesh Actions or another CI system. Evidence: [`git-compatibility.md` §repository-controlled-server-hooks-are-disabled](git-compatibility.md#repository-controlled-server-hooks-are-disabled). Verified 2026-09-14.
- Failover happens only before a response starts; an interrupted fetch must be retried. Evidence: [`git-compatibility.md` §a-response-cannot-change-mirrors-mid-stream](git-compatibility.md#a-response-cannot-change-mirrors-mid-stream). Verified 2026-09-14.
- No network service role is fully independent of the hosted deployment yet. Evidence: [`service-roles.md` §role-status](operations/service-roles.md#role-status); [test `test_no_role_overclaims_independence`](../../app/tests/test_service_roles_contract.py). Verified 2026-09-14.
- Private repositories are not commercially generally available until keyless inspection, recovery drills, and an independent review pass. Evidence: [`private-repository-confidentiality.md` §ga-evidence](security/private-repository-confidentiality.md#ga-evidence). Verified 2026-09-14.

## Migration cost

- Imports from GitHub, GitLab, Codeberg, and Gitea run as resumable jobs with checkpoints; a failed or abandoned import can be recovered or rolled back. Evidence: [`repository-imports.md` §failure-abandonment-and-rollback](repository-imports.md#failure-abandonment-and-rollback); [test `test_abandon_recover_rollback_and_credential_non_persistence`](../../app/tests/test_repository_migration.py). Verified 2026-09-14.
- A public import stops depending on its provider only after a mirror node hosts it. Nodes refresh every 30 minutes, cap imports at 20 GiB and a first clone at 10 minutes, and never host private imports.
