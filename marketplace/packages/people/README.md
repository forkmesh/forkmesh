# People

People: everyone around a campfire, the most active closest to the flames.
Pick someone to see their profile, follow them or send a message.

Surfaces: desktop (rail page), iPhone and Android (menu, `/dashboard/people`),
the web (`/dashboard/people`).

The rings, from the fire outwards:

| Ring | Who sits there |
| --- | --- |
| Blazing | Active today and deep in the work |
| Glowing | Active in the last five days |
| Kindling | Joined in the last two weeks |
| Warm | Active this month, or has contributed |
| Embers | Quiet for a while |

The install state follows your ForkMesh account. It is off until you install
it from the Market.

How the rings are worked out, where each platform's code lives and how the
shared test fixture keeps them in step: `docs/marketplace/people.md`.
