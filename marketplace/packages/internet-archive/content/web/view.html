Internet Archive

Back up public repositories to archive.org, then check every copy against that independent record, even when the repository's source is offline.

Install Internet Archive

Uploads a Git bundle of your public repositories to an archive.org item with your own keys, and compares every mirror with it so you can tell which copies are genuine when the source is down.

Pick a repository

Enter a public repository as owner/name, or open one of your backups above. Any public repository with a backup can be checked; only its owner can change the backup.
