# Shortcuts

Shortcuts: one-tap commands from a repository's .forkmesh folder, run on your desktop or on the phone.

Surfaces: desktop, iPhone, Android.

It ships five starter prompt shortcuts in `content/shortcuts/` that work in any
repository: review my changes, audit the user experience, retire stale code,
refresh the documentation and propose a feature to retire. The desktop's
Shortcuts page offers **Add starter shortcuts** for a repository that has none,
and the web Workflows page lists them as package files you can add.

The install state follows your ForkMesh account: removing it on one device
removes it from every device, and installing it brings it back everywhere.

It is off in projects and accounts created from 2026-10-11; older ones keep it
installed until it is removed (`install.installedBefore`).

The feature itself is built into each app; the package is its on/off
switch. See `docs/marketplace/core-plugins.md`.
