# VSCodium preview

VSCodium adds a **Codium** button to the desktop's branch diff header. Clicking
it opens the reviewed branch's worktree (or the repository checkout when the
branch has none) in VSCodium, found as `codium` or `vscodium` on `PATH` or, on
macOS, inside `/Applications/VSCodium.app`.

The package is bundled but not installed by default. Install it from the Market
to bring the button back; removing it takes the button away again.

`market.png` is the required Market listing screenshot. It shows the branch
diff header with the Codium button the package contributes.
