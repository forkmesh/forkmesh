# ForkMesh Aquarium Sky Office preview

The preview shows the opt-in round aquarium island, its tall glass lift,
summit workspace, drone roof, and the twin-tube hyperloop connection back to
the mainland.

The package is bundled but switched off by default: its module is not part of
the World's initial download. A visitor installs it from World Settings →
Marketplace; removing it takes its scene roots, raycast targets, sounds,
movement hooks, and animation work back out of the World.

The package makes no network requests of its own. Floor access comes from the
host's existing Office access hydration.

`market.png` provides the required visual preview for the unified Market list.
