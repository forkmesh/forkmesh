                          Downloads, redownloads, updates, countries and devices come from App Store Connect's daily sales reports. Apple publishes a day's report the next morning, Pacific time, so every range ends on the last reported day. The App Store Connect key never leaves the computer that runs the App Store report (native/ios/tools/asc_store_report.py --publish); it sends the daily numbers here. Rating, ratings count and the store listing are read from the public App Store by Refresh.

                          Connect X (Twitter)

                          Owners and admins can post from Marketing with the organization's own X app. The keys are stored encrypted and are never shown again.

                          Let the browser extension walk you through it.

                          It opens X's developer console in a new tab and guides you page by page: it fills in X's forms, presses the generate buttons, reads the four keys off the page and saves them here. You only sign in to X, tick X's agreement boxes and add API credits yourself.

                          Or do it yourself:

                          1. Open X's developer console and create an app.
                          2. Under User authentication settings, give the app Read and write permission.
                          3. Under Keys and tokens, copy the API key and secret, then generate an Access token and secret for the account that should post.

                          A visit converts when it records one of these Analytics events. Use the event your site already sends: a pageview of the signup or download page, or a button's product action. Up to 5 goals.

                          Weekly marketing report

                          Scorecard, experiments, ads, content and the Reddit desk in Markdown, ready to paste into a plan, an issue or a special agent's run.

                          Log thread

                          Paste the address of a thread you opened and read yourself, or let the ForkMesh browser extension send the threads you open. ForkMesh stores what you or the extension record and never opens the thread itself.

                          The tagged link lands on a top-level forkmesh.com page, such as / or /download/.

                          Replied needs both boxes ticked and the address of the reply you posted yourself.

                          A monitored thread’s views, points and comments, and those of its comment (or your reply when no comment is set), are read by the ForkMesh browser extension from your own signed-in Reddit tab. Reddit shows view counts only to the person who posted, so open it from that account. Pasting a comment link as the thread address fills this in.

                          Add post

                          A post or comment you made on Reddit. Its numbers are what Reddit showed you; the ForkMesh browser extension updates them when it reads your profile, and fills them for you on the next Update.

                          Leave a number empty when you don't know it. Saving numbers records a new reading, so the post's history keeps the earlier ones.

                          Reddit watch list

                          Up to 40 subreddits and 40 searches. Each becomes a link that opens Reddit in your browser; ForkMesh’s servers never read them. The ForkMesh browser extension reads only these subreddits and searches when you open them.

                          Log channel metrics

                          Record a point-in-time snapshot from a channel dashboard. Each snapshot becomes a point on the trend chart.
