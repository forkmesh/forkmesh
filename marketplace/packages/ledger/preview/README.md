# Ledger preview

Ledger contributes a **Ledger** icon to the ForkMesh desktop's left rail. The
icon opens the active ForkMesh host's public financial system of record in the
default browser, including pending payments, completed on-chain transfers,
exact SOL values, USD estimates, transaction IDs, and source links.

Beside the relay's public records the page keeps the reader's own book: an
entry form records any other expense or income, in SOL or dollars, and those
entries stay in this app's settings on one machine. They are never published,
so the relay's ledger remains the only public financial record.

`market.png` is the required Market listing screenshot. It shows the ledger the
installed contribution opens: loaded records, on-chain receipt counts, exact SOL
sums, USD estimates, and per-row transaction IDs. The live ledger remains the
source of truth for behavior; the image is a bounded preview rather than
executable package content.
