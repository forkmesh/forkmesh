# Tour preview

Tour contributes the first-run welcome card and the guided feature tour to the
ForkMesh desktop, plus a **Tour** button in the rail that replays it. Each step
spotlights the real control it describes. It is installed by default; remove
it from the Market or by right-clicking Tour in the rail, and install it again
from the Market whenever you want the walkthrough back.

`market.png` is the required Market listing screenshot, rendered from the
package's own overlay widget.
