# Tour preview

Tour contributes the first-run welcome and the guided feature tour to
ForkMesh, plus a **Tour** button in the desktop rail and a Tour icon on the
phone's Home. Both offer three depths: **Essentials**, **Advanced** and **The
whole shebang**.

On the desktop each step spotlights the real control it describes. On the
phone each stop shows a working miniature of the screen it describes, which
you can try right there, and a button that opens the real one.

It is installed by default; remove it from the Market or by right-clicking
Tour in the rail, and install it again from the Market whenever you want the
walkthrough back.

`market.png` is the required Market listing screenshot, rendered from the
package's own overlay widget.
