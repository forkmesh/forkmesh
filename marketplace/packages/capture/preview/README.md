# Capture preview

Capture contributes a **Capture** action to the ForkMesh desktop rail. It opens
a user-controlled region selector, then an annotation window with pencil,
filled shapes, arrow, multiline resizable text, clipboard image layers that can
be moved or resized, copy, discard, and **Add to Prompt** controls.

`market.png` is the required Market listing screenshot. The installed
contribution remains the source of truth for behavior; the image is a bounded
preview rather than executable package content.
