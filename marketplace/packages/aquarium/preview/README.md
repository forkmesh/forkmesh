# Aquarium preview

Aquarium turns the whole ForkMesh desktop window into an aquarium while
ForkMesh is not the active app. Every agent is a fish, drawn by its status,
changed files and conflicts, that plays with the window's buttons, headings, rows and text boxes and with the Genie spider.
Its **Aquarium** rail page has the on/off switch, the delay and **Show it
now**.

`market.png` is the required Market listing screenshot, rendered offscreen from
the package's own overlay over a sample Agents page.
