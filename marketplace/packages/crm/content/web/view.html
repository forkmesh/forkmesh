    Set up Zoho OAuth

    A. One-click Connect Zoho Mail for every organization

    Done once by the server operator. Afterwards an owner or admin of any organization only clicks Connect Zoho Mail.

    1. Open the Zoho API Console, sign in with the Zoho account that owns the company mail, and choose Add Client → Server-based Applications.
    2. Client name ForkMesh CRM, homepage URL https://forkmesh.com, Authorized Redirect URI exactly:
      https://app.forkmesh.com/api/crm/-/zoho/callback
      Click Create.
    3. Open the client's Settings tab, turn on Multi-DC (so accounts in the EU, IN, AU, JP and CA data centers can sign in) and save.
    4. On the Client Secret tab copy the Client ID and the Client Secret.
    5. On the operator machine add these lines to ~/projects/forkmesh/config/fleet/secrets.env with the two values filled in:
      PACKAGE_CRM_ZOHO_OAUTH_CLIENT_ID=<client id>
PACKAGE_CRM_ZOHO_OAUTH_CLIENT_SECRET=<client secret>
PACKAGE_CRM_ZOHO_OAUTH_REDIRECT_URI=https://app.forkmesh.com/api/crm/-/zoho/callback
      The redirect line lets the desktop start the sign-in; a desktop request has no browser origin.
    6. Add the three names to optional_secrets in deploy/fleet.toml, run tools/next_vault.py sync to check the plan, then tools/next_vault.py sync --execute.
    7. Reload this page. The line at the top of this guide then says one-click is on. Click Connect Zoho Mail, sign in to Zoho and press Accept; you come back here and the first sync runs.

    B. This organization only, without a server change

    1. In the Zoho API Console choose Add Client → Self Client and click Create. Copy its Client ID and Client Secret.
    2. On its Generate Code tab enter the scope
      ZohoMail.messages.READ,ZohoMail.folders.READ,ZohoMail.accounts.READ
      pick 10 minutes, click Create and copy the code.
    3. Within those 10 minutes click Enter in CRM settings below, paste the client ID, the client secret and the code, and click Connect with code. ForkMesh redeems the code itself, tries every Zoho data center, reads the mail account id and runs the first sync. No curl needed.

    The CRM only reads mail. The client secret and refresh token are stored encrypted and are never shown again.

    New pipeline

    A pipeline is a flow with ordered stages. It opens as its own tab listing every contact in it, and the browser extension can add contacts to it from Gmail or Zoho Mail.

    Pipelines

    A pipeline is an ordered set of stages contacts move through, and its type is the icon on its tab. A list bound to a pipeline shows every contact in it. Removing a pipeline leaves the contacts in it without one.

    Add members

    List

    A list holds the contacts you put on it. Give it a pipeline and it walks them through that pipeline's stages; several lists can share one pipeline without sharing contacts. Choose who can open it: your organization, picked teammates, or any ForkMesh user by name.

    Import Mastodon followers

    Your browser reads the account's public follower list from its own instance, then each follower becomes a contact on a list you name next. Importing the same account again updates the followers it brought in before.

    Import GitHub contributors

    Your browser reads the repository's newest commits from GitHub's public API, then every author, committer and co-author email becomes a contact on a list you name next. GitHub's masked addresses (users.noreply.github.com) and other no-reply addresses are left out. Importing the same repository again updates the contributors it added before.

    Browser extension

    The ForkMesh browser extension for Chrome adds a CRM header and a "Link to CRM" panel inside Gmail, Zoho Mail and the Mastodon instances you add to it. Linking keeps the message id on the contact's record here, and clicking the record reopens the message in that mailbox. The extension is its own Market package: its page installs and updates it, and the same extension fills logins from the Password Vault. Sign in with your ForkMesh account inside the extension, then press Reload from Extensions page after an update.
