# Forum

The Forum tab of a repository: a Discourse-style forum with categories and
subcategories, tags, Latest and Top lists, and topic pages with their posts,
likes and views.

The forum is kept in the repository itself (`.forkmesh/forum`), so every
mirror and every clone carries it. A repository owner turns the tab on under
Settings → Features. Today a forum is filled by copying a Discourse forum with
the Discourse Mirror plugin; posting, likes and the operator tools on ForkMesh
come next.

Surfaces: the web. The desktop, iPhone and Android follow.

The feature itself is built into the web app; the package is its on/off
switch. See `docs/app/repo-forum.md`.
