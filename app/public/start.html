Check the server's fingerprint (optional)

On the server, run ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub. ForkMesh stops if the server answers with a different key. Left empty, the key the server shows first is trusted and shown in the setup log.

3

Your address

Point your domain at the server, or leave it empty to start on a free address right away.

At your DNS provider, add an A record for this name pointing at your server's IP. Setup waits for it and then gets an HTTPS certificate. On Cloudflare the proxy can stay on; set SSL/TLS to Full (strict).

4

The first user of your instance. You sign in with it to manage everything.
