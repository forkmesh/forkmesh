Runners

Machines that run agent jobs. Sign a runner's Claude Code or Codex CLI in from here: the runner runs the provider's own login in a terminal and this page shows it. The credential is created and kept on the runner; ForkMesh relays only the terminal, and hides anything that looks like a token. A runner can keep several accounts per provider: every job uses the active one, and you can switch at any time. Each account shows its current usage limits.

Set up a runner

A runner is a Linux machine of yours that runs your agent jobs with its own Claude Code or Codex login. It serves no repositories and only takes jobs you send it.

Run this on any Linux machine with systemd. It installs the signed ForkMesh runner and registers it as your personal runner. The command holds a one-time token that works once, only for this runner name, for 30 minutes.

No desktop? ForkMesh can connect for you from its servers. It checks the server's host key first, then uses your password or key once, in memory, to run the installer.                         Host key (trust on first use)
                        

                        
Compare it with the server's own key before you go on: run ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub on the server, or check your hosting provider's console. ForkMesh connects only to a server that shows this key.
