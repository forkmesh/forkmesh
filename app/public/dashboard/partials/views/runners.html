Runners

Machines that run your agent jobs with their own Claude Code or Codex sign-in.

How sign-in works

Sign a runner's Claude Code or Codex CLI in from here: the runner runs the provider's own login in a terminal and this page shows it. The credential is created and kept on the runner; ForkMesh relays only the terminal, and hides anything that looks like a token. A runner can keep several accounts per provider: every job uses the active one, and you can switch at any time. Each account shows its current usage limits.

Set up a runner

A runner is a Linux or macOS machine of yours that runs your agent jobs with its own Claude Code or Codex login. It serves no repositories and only takes jobs you send it.

Run this on a Linux machine with systemd, or on a Mac running macOS 12 or newer. It installs the ForkMesh runner and registers it as your personal runner. The command holds a one-time token that works once, only for this runner name, for 30 minutes.
