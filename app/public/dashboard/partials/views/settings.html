    Push code over HTTPS

    Nodes

    A node is one ForkMesh install - the desktop app on your machine, or a headless node you deployed on a server. Nodes hold the repositories and drain this account's issues, comments, chats and pull requests off the relay, so linking at least one is what makes anything you write on the web actually sync.

    No node is linked to this account yet

    That is what "Reconnect node" in the header is about: until a node links, everything you write on the web is parked on the relay and no machine of yours is serving your repositories. Nothing is lost - it drains as soon as a node comes online. Claim a node you already run below, or start one from "No node yet?" at the bottom of this page.

    Link a node

    Linked nodes

    • No linked nodes yet.

    Claim ownership of a node you already run (e.g. a headless mirror you installed) by entering its node ID below. A confirmation code will appear on that node - enter it here to finish linking it to your account. Tip: clicking "Link this node to your account" in a node's own app links it here with no code at all.

    What is a node ID?

    It names the node you want to claim - not your ForkMesh username, email or password. Either form is accepted:

    • the node's name: lowercase letters, digits and hyphens, starting with a letter, e.g. mirror-01
    • the node's public key: exactly 43 characters of letters, digits, - and _, e.g. J2MJT8PgCi665wAlfuHdmpl-WDH2xB6z3Tp6T0OPsOs

    Both live on the node itself: open ForkMesh on that machine, go to Profile, and use "Copy node ID" under NODE ID (PUBLIC KEY). For a headless node, it is the name you gave it when you ran the installer.

    No node yet? (browsing from the web only)

    You do not need one to read, sign in or write - but you do need one for your account to own repositories and to drain what you write off the relay. Two ways to get one, both of which link themselves to this account:

    • Install the desktop app from the downloads page, then click "Link this machine to your account" on its Profile page. No node ID and no confirmation code to type.
    • Or run a headless node on any always-on machine with curl -fsSL https://forkmesh.com/install.sh | bash, then claim it above by the node name you gave it.

    Repositories you cannot open in the meantime are waiting on a host: their owner's node or a mirror has to be online to serve them, and linking your own node is what puts yours back online.
