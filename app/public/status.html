How this page measures uptime

Uptime is computed only from samples that were actually recorded; minutes where the sampler itself didn't run are red monitoring failures. Missing, stale, empty, and rate-limited monitoring use distinct red shades so they cannot be confused with an observed service outage. Click a system to see exactly what its check tests.

We are still tuning monitoring and optimizing traffic usage for bots. On an upgraded instance, the API and scheduled checks fail closed rather than report operational while a historical Worker-held wallet key still requires the documented offline export, zero-balance reconciliation, and scrub.
